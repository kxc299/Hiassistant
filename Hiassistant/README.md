# 海信一体机 助手（手动控制 + 定时计划 + 联动设置 + 个性化与工具）

四个标签页：**手动控制 / 定时计划 / 联动设置 / 个性化与工具**；含开机自启、10 秒倒计时确认、可自定义全局快捷键、托盘/完全后台、休眠键联动、息屏守护、端口锁定、定时精确到秒、皮肤与字体、自定义外部命令、命令行调用。命令帧来自集控自带 `cmds.xml` 与对 `HiRemote.exe`（.NET）的反编译核对，并与海信 E/M/WR 系列 RS232 官方控制手册（9600 8N1、HEX）一致。

## 本轮更新（纯 Go 单 exe：关机/重启联动 + 顶部标签消失根因修复）

1. **回到纯 Go，无 DLL、无注入**：不再需要 `shutdown_hook.dll`（`hook_inject.c` 仅作历史参考，不参与构建）。交付为**纯 Go 单 exe**，与 `plan.json` 同目录即可。
2. **修复“顶部四个标签条消失”的真正根因**：
   - 现象：一旦给窗口设置皮肤背景，顶部“手动控制/定时计划/联动设置/个性化与工具”标签条就不显示；
   - 根因（walk 库机制）：主窗口设了自定义背景刷后，TabWidget 会走自绘标签分支，而该分支**仅当 TabPage 布局边距非零时**才会调用 `DrawThemeTextEx` 绘制标签文字；我们之前每个 TabPage 用 `NewVBoxLayout()`（默认零边距），导致整段自绘被跳过、标签文字不画；
   - 修复：给每个 TabPage 布局设 9px 边距（`newTabPageLayout()`），标签文字在任意皮肤下都正常重绘。同时回退了上一版“递归覆盖容器背景”的过激改动，恢复原来稳定的皮肤渲染。
3. **Windows 关机联动逻辑**：
   - **注销**：由 `ENDSESSION_LOGOFF` 位精确排除，不联动；
   - **关机 / 重启**：Windows 的 `WM_QUERYENDSESSION/WM_ENDSESSION` 不区分两者、消息参数不含关机类型，纯 Go 无法在关机瞬间可靠区分，故统一视为“系统结束会话”，联动关闭整机；
   - 若不希望重启时联动，可在“联动设置”关闭该开关。
3. **皮肤个性化**：恢复默认皮肤渲染（不再递归覆盖容器背景）；“恢复默认”按钮清空自定义背景图/色；设置保存在 exe 目录的 `plan.json`，只读/压缩包内运行不可写时页面会明确提示。
4. **注意**：真实串口联动请在**真实一体机**（锁定 COM1）上验证（虚拟机无 COM1，打开 COM1 失败属正常）。
5. 发布到 GitHub / 论坛的具体步骤见同目录 **《发布指南.md》**。

## 上一轮更新（皮肤修复 / 透明度 / 全窗口皮肤 / 隐藏设置扩展）

1. **修复“背景色/文字色按钮点击无效”**：系统颜色对话框 `ChooseColorW` 的结构体大小在 64 位下填错（应为 60 字节却填了 36），导致对话框直接失败。现用 `unsafe.Sizeof` 正确填充，按钮可正常弹出色板。
2. **修复自定义图片皮肤“显示不全、卡顿”**：位图背景只在窗口最外层可见、被各标签页控件盖住故显示不全；且每次切换都重新加载大图导致卡顿。现：图片按路径缓存、超大图（>1920×1080）自动缩放后再平铺；配合“全窗口皮肤”可铺满整窗。
3. **新增窗口透明度**：个性页新增「窗口透明度」下拉（100%/90%/80%/70%/60%），通过 `WS_EX_LAYERED + SetLayeredWindowAttributes` 实现，即时生效。
4. **新增全窗口皮肤**：个性页新增「全窗口皮肤（整窗同色）」开关，开启后递归给所有标签页/容器应用皮肤背景（纯色/图片），整窗背景一致；仍不触碰按钮/输入框等原生控件文字色，避免文字消失。
5. **高级隐藏设置新增“隐藏阻止键鼠唤醒选项”**：托盘「高级隐藏设置…」新增勾选项，开启后联动页的“休眠时阻止键鼠唤醒”选项将被隐藏。
6. **随包交付源码**：附 `海信一体机助手-源码.zip`（全部 .go、go.mod、清单、README、plan.json、hook_inject.c、shutdown_hook.dll），可直接用 Go 交叉编译复现。

## 历史更新（定时空动作修复 / 守护重写 / 关机联动 / 命令行 / 皮肤）

1. **修复定时任务“显示已执行但无任何响应”**：日志显示保存的计划动作键为空（`未知动作: `）。根因是添加计划对话框依赖 `combo.Text()` 回读，在分类切换/对话框未显示时可能为空。现改为变量显式跟踪选中动作键，保存前强制校验（空动作直接拦截并提示）；调度器对空动作也会明确报错并记录，不再静默“已执行”。
2. **息屏守护重写为定时查询屏幕状态**：
   - 按“检测间隔”周期性查询屏幕状态帧（C1 32），查到**已息屏但 PC 未休眠**（且最近 8 秒无键鼠活动）则自动让 PC 睡眠；
   - 新增选项 **“应用拦截休眠时不休眠”**：通过 `powercfg /requests` 检测播放音乐/视频等系统占用，存在占用时跳过本次睡眠；
   - 新增选项 **“休眠时阻止键鼠唤醒计算机”**：睡眠前对键盘/鼠标类唤醒设备执行 `powercfg /devicedisablewake`，系统恢复后自动重新启用（该 powercfg 操作可能需要管理员权限，失败会在日志说明）。
3. **快捷键新增“显示主窗口”动作**（默认 Ctrl+Alt+R）；原固定呼出键 Ctrl+Alt+Shift+M 仍可显示↔隐藏切换。
4. **监测 Windows 关机并自动关闭整机**：监听窗口处理 `WM_QUERYENDSESSION`/`WM_ENDSESSION`，检测到关机/重启/注销时在系统终止进程前同步下发整机关机帧（只发一次）。
5. **命令行 / 自定义命令 / 第三方调用**：
   - 支持 `--action <键>`、`--frame "<HEX>"`、`--port <COMx>`、`--run <名称>`、`--list-actions`、`--help`，无头执行，第三方程序/脚本可直接调用；
   - “个性化与工具”页可维护自定义外部命令（名称/路径/参数），并自动出现在主菜单与托盘的“自定义命令”子菜单。
6. **UI 流畅度与皮肤**：一键息屏等睡眠动作全部移出界面线程；新增 5 套皮肤（经典/商务蓝/深色/护眼绿/暖沙色，含深色标题栏）与 4 档字体大小，选择后即时应用并持久化。注：walk 基于 Win32 原生控件，深色皮肤下按钮/复选框等仍为系统原生外观，无法像网页一样完全改色。

## 历史修复（休眠不生效 / 串口占用 / 重复实例 / 压缩包运行）

1. **休眠守护“一闪而过却不睡眠”**：根因是旧代码用 `shutdown /h` 触发休眠（系统未开启休眠时会闪一下命令行窗口并失败）。现改为系统 API `powrprof!SetSuspendState`（睡眠、强制进入、无黑窗）；API 失败再回退隐藏窗口的 `shutdown /h /f`。定时 `sleeppc` 与一键息屏同样改用该 API。
2. **串口 Access is denied / 亮屏失败**：守护轮询、手动按钮、定时动作可能同时抢占 COM1。现所有串口操作加全局互斥串行化，打开串口遇“被占用”自动重试 5 次（每次 250ms）。
3. **单实例**：防止多开导致全局热键互相占用（日志里 Ctrl+Alt+S 报 Hot key is already registered）和串口抢占；再次双击会提示“已在运行”。
4. **压缩包临时目录提示**：若直接在压缩包内运行（读不到 plan.json、设置不保存），启动时弹窗提示先解压到固定文件夹。

## 已具备功能（依据集控 cmds.xml 与反编译）


### 1. 手动控制菜单扩充（依据集控 cmds.xml）
- **信号源切换**子菜单：OPS / HDMI1 / HDMI2 / VGA1 / AV1 / YPbPr，以及**查询当前信源**（`C1 1A`）。
- **图像模式**子菜单：标准 / 运动 / 录音 / 电影 / 游戏（`C1 0F 06`，校验已按长度起逐字节异或核对）。
- **同步本机时间到整机**：一次下发设置日期（`C1 1C`）+ 设置时间（`C1 1D`）。
- **每日定时开/关机**（`C1 30/31` 带 `FF` 的每日重复时间，区别于带日期的 RTC 帧）。

### 2. 标签页三：联动设置
- **全局快捷键（可自定义、防冲突）**：默认可在联动页自行选择 Ctrl/Alt/Shift 与按键，默认组合：
  - `Ctrl+Alt+S` 一键息屏（息屏+PC休眠）
  - `Ctrl+Alt+D` 仅息屏（含未休眠守护）
  - `Ctrl+Alt+W` 亮屏
  - `Ctrl+Alt+Q` 查询屏幕状态
  - 固定呼出热键 `Ctrl+Alt+Shift+M` 不可修改（后台/托盘恢复用）。
- **托盘 / 后台**：启动最小化到托盘、完全后台（无窗口无托盘）、立即隐藏到托盘。
- **PC 休眠键联动**：低级键盘钩子（WH_KEYBOARD_LL）捕获键盘 `Sleep`（VK_SLEEP）键，按下即自动对整机关闭显示；两种模式：
  - 仅息屏并**拦截系统休眠**（吞掉 Sleep 键，不真正睡）；
  - 息屏后**继续让 PC 休眠**（放行 Sleep 键）。
- **仅息屏后守护**：仅息屏后开始轮询，可设等待秒数（默认 60）；期间每 10 秒检查一次键鼠活动（GetLastInputInfo）与屏幕状态（串口 `C1 32`）：
  - 有人操作 / 屏幕被点亮 → 自动取消休眠；
  - 一直无人操作且 PC 仍未休眠 → 到时执行 `shutdown /h` 休眠。
  - 对「仅息屏」菜单、热键 `Ctrl+Alt+D`、定时计划 `screenoff` 动作均生效。

> 说明：低级键盘钩子/全局热键可能触发安全软件提示，属正常；钩子在独立线程消息泵运行，不阻塞界面。

    - 快捷：静音、音量 50/100、亮度 30/60/100；
    - 通电状态：上电自启 / 上电待机（`C1 FF 00 09`，语义待实测）；
    - RTC：写入定时开机 / 定时关机（按下方时间）、取消定时开机 / 关机。
  - 原来的「仅息屏」已放入二级菜单，主界面更简洁。
- 音量 / 亮度（0–100）设置；整机 RTC 定时开关机写入 / 取消；自定义帧发送。
- 发送/回执日志区（同时写入 `control.log`）。

## 标签页二：定时计划（原 HisenseScheduler）

- 顶部：海信网关路径、启用定时开关、应用。
- **开机自启**：勾选后写入当前用户开机启动项（`HKCU\...\Run`，免管理员）；之后每次开机登录都会自动启动本程序并自动开始调度。
- 回退串口：网关不可用时直接发该串口。
- 计划表格（勾选=启用）：添加 / 编辑 / 删除 / 立即执行所选；动作可选：
  - 关机 poweroff
  - 息屏+休眠 sleeppc
  - **仅息屏 screenoff**
- 启动调度 / 停止调度；运行日志写入 `scheduler.log`，每 30 秒检查，同一天同一计划只触发一次。
- **自动执行前 10 秒倒计时确认（开关）**：勾选后，每次自动到点会先弹出倒计时确认框（大号数字 10→0）：
  - 倒计时到 0 自动执行（无人值守也照常执行）；
  - 可点「立即执行」马上执行，或点「取消本次」跳过（回车=立即执行，ESC=取消）；
  - 该开关仅对**自动定时触发**生效；「立即执行所选」为手动操作，不弹倒计时。
  - 开关状态写入 `plan.json` 的 `engine.confirmCountdown`，默认开启。

## 本次修复与增强

1. **修复「启动调度/停止调度」一点就卡死（定时功能无法使用）**：根因是启动/停止函数已持有调度锁，内部又调用会再次加同一把锁的状态更新函数，Go 的互斥锁不可重入，导致 UI 线程自锁。已拆分为持锁版本，死锁消除。
2. **修复「读取/保存 plan.json 卡死」**：上述死锁正好发生在读取 plan.json 之后，表现为“读配置卡死”；一并修复，配置读取/保存均不再阻塞界面。
3. **息屏改为菜单式**：主按钮「一键息屏（息屏+休眠）」，「仅息屏」下沉到二级菜单；菜单内新增静音、音量/亮度快捷档、通电状态（待实测）、RTC 定时等更多可调用功能。
4. **序号模糊**：原 ①②③ 圆圈数字在 Windows 常用字体里渲染偏小、发虚，已改为普通数字（功能现已并入菜单）。
5. **高分屏模糊**：清单加入 `PerMonitorV2` DPI 感知，窗口与文字按真实 DPI 清晰渲染。
6. **开机自启**：勾选即可，登录后自动起程序并自动开始调度；取消勾选即移除启动项。
7. 沿用此前已修复的：主窗口显式 `Show()`、绑定主 OS 线程、所有错误写入 `crash.log` 并弹窗。

## 注意事项

- 先在「手动控制」页自动探测串口，并用 1/3 按钮验证息屏/亮屏；再到「定时计划」页配置与启动。
- 串口若被集控网关常驻独占，需先解绑或用独立 RS232 口；不同机型固件命令族可能不同，上线前请实测。
- 仅息屏只关显示，OPS 仍耗电；省电/放学安全场景用「关机」。
- 纯 Win32 x64 程序（Windows 10 及以上），无需安装运行库；仅适用于你有权管理的自有设备。

## 反编译/配置核对结论（来自 HiRemote 与 cmds.xml）

- 集控 `HiRemote.exe` 为 .NET 4.5 程序，串口/定时逻辑位于 `CCComService`（`com_DataReceived`、`ComSend`）、`CommandExecuteJob`/`AddCmdScheduleJob`（Quartz 定时）、`poweroffHanler`（`EWX_POWEROFF`/`EWX_SHUTDOWN` 关机、`powerofftimer` 倒计时）；命令参数表在 `cmds.xml`。
- `cmds.xml` 中的息屏/亮屏是**旧式** `C1 19` 帧；运行时实际下发的是 `C1 FF 00 12`（Communication 硬编码），本程序沿用运行时帧，同时补充了 cmds.xml 里的信源、图像模式、校时、每日定时等命令。
- `WMControl.DLL` 实为 WPF GIF 解析库，非控制库；真正的控制逻辑在 `HiRemote.exe`。
- 计划/命令仍优先经 `HiRegistrationService.exe` 网关下发，失败回退串口直发（9600 8N1）。
